Agile Pulse UI/UX Design System

Architecture & Design Decisions

This internal tool leverages a Glassmorphism design pattern combined with a deeply tailored Dark Mode. The goal is to provide a premium, dynamic feel for internal tools which are often neglected in terms of UX.

Tech Stack Synergy

  • Java / Spring Boot: Robust, heavily-typed backend ensures enterprise-grade stability and strict data contracts via REST APIs.
  • AI Sentiment Analysis: Heuristic NLP engine built purely in Java to detect burnout risk and flag at-risk team members automatically.
  • Gamification Engine: XP tracking, leveling, and achievement badges incentivize daily engagement and team collaboration.
  • Vanilla JavaScript (ES6+): We deliberately avoided heavy frontend frameworks to keep the repository language strictly Java.
  • Tailwind CSS via CDN: Allows rapid, utility-first styling with custom configurations injected at runtime.

Micro-Interactions

Subtle animations on hover, drag-and-drop state transitions, confetti celebrations, and asynchronous UI updates create a "living" application. The Kanban board utilizes native HTML5 Drag and Drop API with custom CSS scaling effects.
